# LoopRainOS：一个运行在浏览器中的桌面系统

LoopRainOS 是一个把桌面操作系统体验搬进浏览器的 Vue 项目

## 项目简介

这是一个面向个人主页、项目展示和博客写作的 WebOS。打开网页后，你可以像使用桌面系统一样打开文件管理器、浏览器、音乐播放器、终端和设置窗口。

项目使用 Vue 2、Vue Router、Vuex、Vuetify 和 Tailwind CSS 构建，界面保留了轻量桌面系统的窗口、任务栏、侧边栏和壁纸等元素。

## 博客与文件

- 支持使用 Markdown 展示博客文章
- 管理员可以在网页内编辑 Markdown 博客
- 管理员可以新建博客文件和修改文件名
- 游客只能阅读公开内容，不能编辑或管理文件
- 浏览器本地会保存管理员的文章修改和文件操作

## 常用功能

### 文件管理器

文件管理器支持目录浏览、文章打开和文章预览。Markdown 文件会在独立窗口中渲染，适合展示简历、项目说明和技术文章。

### 窗口系统

窗口可以移动、缩放、最大化、最小化和关闭。底部任务栏会集中显示当前打开的应用，右侧消息栏用于查看项目内容更新。

### 管理员设置

管理员可以在设置中修改头像、用户名、壁纸和登录密码。修改密码需要先验证当前密码，新密码还需要再次确认。

## 本地运行

```bash
npm install
npm run serve
```

启动后访问 `http://localhost:8080`。

管理员密码在部署配置中设置，首次登录后建议立即在设置中修改密码。

## 写在最后

LoopRainOS 仍然是一个持续完善中的个人项目。它更关注浏览体验和界面表达，希望让项目介绍、简历和博客内容拥有一个更有个性的展示空间。
